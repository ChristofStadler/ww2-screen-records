# CLAUDE.md

Context for Claude Code working in this repository.

## What this is

A single-page, static site: a graded index of 212 Second World War films,
television serials and documentaries, arranged by **the period of history they
depict** rather than release date. Styled as a declassified War Department
registry sheet. Published via GitHub Pages at
`https://christofstadler.github.io/ww2-screen-records/`.

## Files

| Path | Purpose |
|---|---|
| `index.html` | The entire site — markup, CSS and data in one file |
| `update_ratings.py` | Fills real IMDb ratings into `index.html` |
| `.github/workflows/update-ratings.yml` | Runs the above on push, monthly, and on demand |
| `.nojekyll` | Stops GitHub Pages running the file through Jekyll |

## Hard constraints

- **`index.html` stays self-contained.** No external stylesheets, fonts, scripts
  or images. It must render correctly from `file://` with the network off. The
  paper texture and favicon are inline SVG data URIs; keep it that way.
- **No build step, no bundler, no npm.** Editing the file is the workflow.
- **No `localStorage` / `sessionStorage`.** State lives in memory only.
- Fonts are system stacks (`Courier New` for body, `Impact` for stamps).
  Don't swap in a webfont.

## Data model

All content lives in the `PARTS` array in the `<script>` block at the bottom of
`index.html`. Ten parts, each with an `items` array:

```js
{
  t:  "Come and See",            // title
  o:  "Иди и смотри",            // original-language title (optional)
  y:  1985,                      // release year
  c:  "SU",                      // country code, shown in the meta line
  k:  "F",                       // form: F film · S serial · D factual
  g:  "A1",                      // grading: A1 A2 B1 B2 C3
  r:  8.4,                       // IMDb rating — written by update_ratings.py, don't hand-edit
  lg: ["Russian","German"],      // spoken languages; drives the Tongue filter
  n:  "A Belarusian boy joins…", // the note under the title
  w:  "…"                        // caveat: adds a red flag (optional)
}
```

- Filter buttons for **language** are generated from the data, so a new language
  needs no other change.
- Entries are placed in the part matching the **history depicted**. A 1957 film
  about 1944 belongs in Part VII. Works spanning the war go in Part X.
- Titles are unique on `(t, y)`. Two entries may share a title if the years
  differ (`Dunkirk` 1958 and 2017, `Das Boot` 1981 and 2018).
- `r` is regenerated by CI. Don't add ratings by hand — pin an IMDb id in the
  `MANUAL` table in `update_ratings.py` instead.

## Testing the filters — read this before touching filter code

There are four filters (Form, Tongue, Made, IMDb above) plus free-text search.
They compose with AND; language selections compose with OR among themselves.

**A bug was shipped here once. Don't repeat it.** Filtering sets the `hidden`
attribute on `.entry` elements. `.entry` also has `display:grid`, and an author
`display` rule beats the user-agent `[hidden]{display:none}` rule — so rows
stayed fully visible while the counter updated correctly. The guard is:

```css
.entry[hidden],.part[hidden],.empty[hidden]{display:none!important}
```

Consequently, **never assert on the `hidden` attribute or on the tally alone.**
Assert on real visibility:

```js
document.querySelectorAll(".entry")           // then filter by offsetParent
```

A good check is that visible-row count equals the number in `#tally` for every
filter state.

Also worth knowing: the page is ~13,000px tall. Changing a filter calls
`revealResults()`, which scrolls back to the filter bar if you're below it —
without that, filtering while scrolled deep strands you past the last row and
looks like nothing happened.

## Accessibility and responsiveness

Keep these working: visible focus rings, `aria-pressed` on filter buttons,
`aria-live` on the tally, `prefers-reduced-motion` honoured (it disables the
stamp animation and the scroll easing), and no horizontal overflow at 390px.

## House style for entry notes

Two or three sentences at most. Say what the film depicts and what makes it
worth the viewer's time, in plain declarative prose. Avoid marketing adjectives.
Where a film is well made but misleads on a point of record, put the correction
in `w` rather than softening `n`.
